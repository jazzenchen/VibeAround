# VibeAround CLI

Install the VibeAround command-line tools from npm:

```bash
npm install -g vibearound
```

The package registers both `vibearound` and `va`:

```bash
vibearound tui
va serve
va launch --profile codex
```

This package includes the native `va`, `va-tui`, `va-launch`, and
`vibearound-server` binaries plus the built web dashboard used by `va serve`.
